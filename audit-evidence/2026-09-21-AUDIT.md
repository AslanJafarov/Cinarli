# Çınarlı Park project audit

Date: 21 September 2026. Scope: repository, public HTTP responses, TLS certificates, production build, lint, dependency audit, and isolated local reproductions. Application source was not changed. Public checks were read-only; submission and data-loss checks used temporary local data.

This report lists findings established during this audit. It does not claim that every possible defect has been found. Browser screenshots, mobile rendering, real administrator sessions, hosting configuration, backups, and Google Maps credentials were not available for verification.

Severity: **High** means a security, availability, data-loss, or primary conversion problem. **Medium** means broken functionality or an operational weakness. **Low** means a maintenance or secondary correctness issue.

## Findings

### 1. High — The live TLS certificate has expired

**Evidence: live.** Both `chinarlipark.az` and `www.chinarlipark.az` serve a Sectigo certificate that expired **15 December 2025, 23:59:59 GMT**. Normal HTTPS requests fail with `CERT_HAS_EXPIRED`.

**Impact:** Visitors encounter certificate errors before reaching the site or admin login.

**Fix:** Renew/install the certificate and full chain for both hostnames, then verify automated renewal. This is a hosting change.

### 2. High — HTTP serves the login and forms without redirecting to HTTPS

**Evidence: live and source.** `http://www.chinarlipark.az/admin/login` returns HTTP 200 and a password form, without an HTTPS redirect. The homepage also stays on HTTP. The login form submits to the current origin. Production session cookies use `secure: true` in [auth.js](src/lib/auth.js#L33).

**Impact:** Passwords and lead information can be submitted over unencrypted HTTP. Secure session cookies also cannot establish a normal production login session on that HTTP origin.

**Fix:** After repairing TLS, enforce HTTPS at the hosting proxy and redirect both hostname variants to one canonical origin.

### 3. High — Search metadata advertises the wrong domain

**Evidence: live.** The homepage canonical is `https://cinarli.az`; `/robots.txt` advertises that host and its sitemap; `/sitemap.xml` lists `cinarli.az` URLs. These differ from the supplied production domain.

**Source:** [seo.js](src/lib/seo.js#L10), [robots.js](src/app/robots.js), [sitemap.js](src/app/sitemap.js).

**Impact:** Search engines and sharing services receive URLs for a different domain.

**Fix:** Set `NEXT_PUBLIC_SITE_URL` to the chosen HTTPS production origin and rebuild. Correct the hardcoded domain shown in [SitePreview.jsx](src/components/admin/SitePreview.jsx) too.

### 4. High — Public contact links still use a placeholder number

**Evidence: live.** Home, apartments, contact, gallery, news, Russian, and English pages advertise `tel:+994500000000` and `https://wa.me/994500000000`.

**Source:** [mock.js](src/data/mock.js#L347); [store.js](src/lib/store.js#L68) also retains these defaults in production when the section has not been replaced.

**Impact:** Primary call and WhatsApp actions point at the sample number rather than a verified sales contact.

**Fix:** Replace the office links, displayed details, and duplicated footer contact values with verified business contacts.

### 5. Medium — `/login` has no route or redirect

**Evidence: live and local.** `/login` returns 404; `/admin/login` returns the login page. [proxy.js](src/proxy.js#L23) rewrites `/login` to `/az/login`, which reaches the [catch-all page](src/app/[lang]/[...rest]/page.jsx).

**Impact:** The login address you tried cannot work with the current routing.

**Fix:** Add an explicit redirect from `/login` to `/admin/login` before locale rewriting. Decide whether localized aliases should also redirect.

### 6. High — Building without admin credentials permanently prerenders the unavailable login state

**Evidence: reproduced locally.** The clean build had no admin environment variables. Next classified both `/admin` and `/admin/login` as static. Starting that build with all three `ADMIN_*` variables set still returned `x-nextjs-cache: HIT`, the “Giriş hələ qurulmayıb” message, and no password field.

**Cause:** [auth.js](src/lib/auth.js#L46) returns before calling `cookies()` when configuration is missing, so rendering never encounters a request-dependent API. See also [login/page.jsx](src/app/admin/login/page.jsx) and [admin/page.jsx](src/app/admin/page.jsx).

**Impact:** Supplying secrets only at runtime does not repair the generated admin pages.

**Fix:** Make admin rendering explicitly request-dependent, or access the cookie API before the configuration early return. Rebuild and verify with secrets supplied only at startup.

### 7. High — The checked-in cPanel deployment tasks do not form a working deployment

**Evidence: source.** [.cpanel.yml](.cpanel.yml#L3) copies `storage`, but that directory is ignored and absent from a clean checkout. It omits `server.js`, dependency installation, building, and restarting. Copying `src` into an existing destination also leaves deleted files behind.

**Impact:** The storage copy fails on a fresh checkout; source changes alone do not replace the running production build. Old routes can survive a deployment. Copying storage would also risk overwriting live data if a source storage directory were later introduced.

**Fix:** Use a defined release process that installs locked dependencies, builds, deploys the required server files, and restarts only after success. Preserve live storage separately. External cPanel/manual steps may compensate, but none are documented in the repository.

### 8. High — The payment calculator does not calculate

**Evidence: source.** [PaymentCalculator.jsx](src/components/PaymentCalculator.jsx#L23) calculates the result once on the server. The editable inputs use `defaultValue`; the calculate button has no handler. Changes to price, down payment, or duration never update the result.

**Impact:** Visitors receive an unchanged payment result after entering different values.

**Fix:** Implement client-side calculation and validation, including a positive duration and a down payment within the price.

### 9. High — Several sales buttons do nothing

**Evidence: source/AST inspection.** Enabled `type="button"` elements have no handler or navigation:

- Apartment picker “apply”: [ApartmentPicker.jsx](src/components/ApartmentPicker.jsx#L381).
- Apartment detail calculator and manager buttons: [ApartmentDetail.jsx](src/components/ApartmentDetail.jsx#L101).
- Contact appointment button: [ContactPage.jsx](src/components/ContactPage.jsx#L89).
- Calculator manager button: [PaymentCalculator.jsx](src/components/PaymentCalculator.jsx#L124).

**Impact:** Visitors reach dead ends in sales enquiries and appointment booking.

**Fix:** Connect each action to a working contact route, relevant form, or calculator, preserving the selected apartment where applicable.

### 10. High — Concurrent content saves and mode changes can overwrite each other

**Evidence: reproduced with the actual storage functions in an isolated directory.** Running `saveData(...)` and `saveMode('production')` together produced a production-mode file without the apartments just saved.

**Source:** [store.js](src/lib/store.js#L95). Both operations read the old file and independently replace it. Atomic rename prevents partial JSON, but does not prevent lost updates. [AdminDashboard.jsx](src/components/admin/AdminDashboard.jsx#L456) allows save and mode actions to overlap.

**Fix:** Serialize read-modify-write operations and add version/conflict checks for multiple admin tabs. Use transactions or cross-process locking when multiple workers share storage.

### 11. High — Saved content has no meaningful schema validation

**Evidence: source and local function checks.** [actions.js](src/app/admin/actions.js#L47) checks only that the top-level value is an object. The JSON importer accepts `apartments: null` and `gallery: 42`. Blank/duplicate apartment and news IDs display warnings but do not block the global save. Apartment IDs also accept URL delimiters and dots.

**Impact:** Ordinary edits/imports can publish invalid structures, duplicate routes, unreachable apartment links, and rendering crashes. A dotted apartment ID is additionally skipped by the locale proxy matcher.

**Fix:** Validate full schemas on the server and surface field errors in the editor. Enforce unique stable IDs, safe path segments, known statuses, required arrays, and numeric bounds.

### 12. High — A damaged leads file is silently replaced with a new list

**Evidence: reproduced locally.** An invalid `leads.json` was read as `[]`; the next `addLead()` replaced it with a file containing only the new submission.

**Source:** [leads.js](src/lib/leads.js#L10). The catch handles missing files, read failures, and JSON corruption identically.

**Impact:** Corruption is hidden and subsequent writes destroy recovery evidence instead of stopping safely.

**Fix:** Treat only a genuinely absent file as an empty collection. Fail writes on other read errors, retain the damaged file, and provide backup/recovery procedures.

### 13. High — The public leads endpoint has no rate limit or duplicate protection

**Evidence: local endpoint and source.** Eight immediate identical submissions to an isolated local server all returned 201. [route.js](src/app/api/leads/route.js#L9) relies on an optional honeypot that a direct request can omit. It also parses the entire JSON body before applying field limits.

**Impact:** Automated submissions can fill the lead list and consume disk/CPU. Every accepted lead rewrites the full JSON file.

**Fix:** Add server-side throttling, reasonable request-size limits, and duplicate/idempotency handling. Hosting-level protection was not inspected.

### 14. High — CSV exports preserve attacker-controlled spreadsheet formulas

**Evidence: reproduced locally.** A public lead with `source: '=1+1'` is accepted and exported as a CSV cell containing `"=1+1"`. The exporter only escapes quotation marks.

**Source:** [LeadsEditor.jsx](src/components/admin/LeadsEditor.jsx#L19), [leads route](src/app/api/leads/route.js).

**Impact:** Spreadsheet applications may interpret untrusted lead fields as formulas when an administrator opens the export. See [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection).

**Fix:** Export untrusted values as explicit text using a format/library that preserves cell types, or apply a spreadsheet-tested CSV protection strategy. CSV quotation alone does not neutralize formulas.

### 15. Medium — Additional apartment photos are uploaded but never displayed publicly

**Evidence: source.** [ApartmentsEditor.jsx](src/components/admin/ApartmentsEditor.jsx#L405) manages `apartment.photos`, but [ApartmentDetail.jsx](src/components/ApartmentDetail.jsx) and the other public apartment components never read that field. Only the plan image is rendered.

**Fix:** Render the saved photos on apartment details, with appropriate image navigation and empty states.

### 16. Medium — Editing gallery photos does not update the homepage gallery

**Evidence: source.** [Gallery.jsx](src/components/Gallery.jsx#L30) prefers `gallery.images`, which is populated by the defaults. [GalleryEditor.jsx](src/components/admin/GalleryEditor.jsx#L53) updates only `gallery.photos` and retains `images` unchanged.

**Impact:** Uploading, reordering, or deleting gallery photos updates `/qalereya`, while the homepage can keep showing the original sample images, including images removed from the full gallery.

**Fix:** Establish one source for homepage selections or expose a separate, explicit homepage gallery selection editor.

### 17. High — Deleting the last object-list entry loses the editor's schema

**Evidence: source.** [FieldEditor.jsx](src/components/admin/FieldEditor.jsx#L284) identifies object lists from their current contents. An empty object list becomes a primitive list; adding an item inserts a string instead of an object.

**Impact:** Removing all FAQ entries, filter options, or other structured rows prevents recreating them correctly through the same editor. Saving such lists can break public components; empty quick-search option lists also leave `selected` undefined.

**Fix:** Define list item schemas independently of existing values and enforce those schemas on save.

### 18. Medium — Partial JSON imports can revert unrelated changes

**Evidence: source.** [AdminDashboard.jsx](src/components/admin/AdminDashboard.jsx#L181) merges imports into `initialData`, the snapshot from when the page opened, rather than the current or last-saved data.

**Impact:** Edit and save one section, then import a partial JSON file for another section: omitted sections can silently revert to their older values.

**Fix:** Merge into the intended current snapshot and show which sections will be replaced.

### 19. Medium — Editing a published news title can change its URL

**Evidence: source and local slug checks.** [NewsEditor.jsx](src/components/admin/NewsEditor.jsx#L116) continues regenerating the ID whenever the current ID equals the slug of the current title, including existing published items.

**Impact:** A title correction can invalidate previously shared or indexed links. No old-slug redirect exists.

**Fix:** Generate the slug once for a new item; keep published IDs stable unless explicitly changed, and preserve redirects when they are changed.

### 20. Medium — Overlong phone numbers are silently changed into different valid numbers

**Evidence: reproduced locally.** [phone.js](src/lib/phone.js#L10) turns `5012345678` into `501234567`; validation then accepts it.

**Impact:** A mistyped or incorrectly pasted number can be submitted as another person's number instead of producing a validation error.

**Fix:** Reject excess national digits after legitimate country/trunk-prefix normalization, rather than silently truncating.

### 21. Medium — Changing language discards filters and fragments

**Evidence: local rendered HTML.** `/en/menziller?rooms=3` generates language links such as `/ru/menziller`, without the query. [Navbar.jsx](src/components/Navbar.jsx#L53) builds them from `usePathname()` alone.

**Impact:** Visitors lose selected apartment filters when switching language; section fragments are also dropped.

**Fix:** Preserve supported query parameters and the current fragment when constructing language links.

### 22. Medium — Modal navigation and the gallery lack keyboard focus management

**Evidence: source; browser verification pending.** [Navbar.jsx](src/components/Navbar.jsx#L112) and [GalleryGrid.jsx](src/components/GalleryGrid.jsx#L28) lock scrolling and handle Escape, but do not move focus into the open dialog, trap focus, make the background inert while open, or restore focus on close. `inert={!menuOpen}` only disables the menu while it is closed.

**Impact:** Keyboard focus can remain on or move to controls behind a modal that declares `aria-modal="true"`.

**Fix:** Use an accessible modal implementation with focus placement, containment, background isolation, and restoration.

### 23. Medium — Floor-plan enlargement is available only on hover

**Evidence: source.** [PlanCard.jsx](src/components/PlanCard.jsx#L109) puts `cursor-pointer` and `hover:scale-160` on a non-focusable div with no click action.

**Impact:** Keyboard users cannot trigger the enlargement, and touch users have no explicit plan-view control.

**Fix:** Provide a named button opening a zoomable plan viewer and retain hover as an optional enhancement.

### 24. Low — Structured data ignores edited apartment-unit totals

**Evidence: source.** [seo.js](src/lib/seo.js#L131) derives `numberOfAccommodationUnits` from imported mock `projectStats`, even when saved project statistics change.

**Impact:** Search metadata can contradict visible project information.

**Fix:** Read the current site's authoritative unit count, rather than the sample data or a translatable label lookup.

## Other operational risks and coverage gaps

- **Live catalogue is empty.** `/menziller` currently shows “Hazırda satışda mənzil yoxdur.” This is confirmed content state, not necessarily a code defect. Publish real inventory if apartments should be offered now.
- **Production can serve sample content.** `productionData()` falls back to mock sections; missing/unreadable `site.json` falls back to mock mode. Sample news and contacts can become public without an explicit publishing step. Whether the current news/project claims are accurate requires business verification.
- **Multiple workers are unsafe for JSON lead writes.** The lead queue is module-local. It does not coordinate separate server processes sharing the same storage. The live process count was not available.
- **Login throttling depends on trusted proxy headers and one process.** `clientIp()` accepts the last `X-Forwarded-For` value (or `X-Real-IP`) without establishing which proxies are trusted. Direct deployments need header sanitization; multiple workers/restarts do not share counters. Production exploitability depends on hosting configuration and was not tested.
- **Storage and responses grow without bounds.** Every lead write reads/rewrites all leads; admin refreshes return all leads; every public layout serializes all localized site content, including all apartments and news, into `I18nProvider`. Pagination, bounded data delivery, and a storage growth policy are absent. This becomes increasingly costly as content grows.
- **There is no automated regression suite or CI configuration in the checkout.** `package.json` contains only dev/build/start/lint scripts. Build success does not catch dead buttons or persistence races.
- **Setup documentation is still the Next.js template.** There is no checked-in environment example or project guide for admin credentials, session secrets, canonical origin, writable/persistent storage, backups, deployment, or Maps configuration.
- **Maps localization remains partly Azerbaijani.** Server lookups hardcode `languageCode: 'az'`, and the client script loader is shared across locales. Full behavior with configured API keys was not tested.

## Suggested repair order

1. Renew TLS, enforce HTTPS, correct the canonical domain and real sales contacts.
2. Repair login routing, dynamic admin rendering, and the deployment process.
3. Add content validation and safe persistence; protect lead intake and exports.
4. Connect the sales buttons/calculator and repair gallery/apartment media behavior.
5. Fix editor edge cases, URL stability, language-state preservation, and keyboard access; add regression coverage around those flows.
